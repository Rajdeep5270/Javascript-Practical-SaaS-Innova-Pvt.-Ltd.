# User Search Table

A small web project that fetches user data from a public API and displays it in a searchable table.

## Why use this project

- Demonstrates how to fetch data from an external API using JavaScript.
- Shows how to render dynamic table content in the browser.
- Includes a live search feature so users can filter results by name.
- Useful for learning basic DOM manipulation and asynchronous JavaScript.

## How to use

1. Open `index.html` in a web browser.
2. Wait for the page to load the user data from the API.
3. Type a name or part of a name in the search box.
4. The table updates immediately to show matching users.

## Files

- `index.html` - page structure and table layout.
- `style.css` - page styling.
- `script.js` - fetches API data and handles live search.

## Notes

- The data comes from `https://jsonplaceholder.typicode.com/users`.
- If there is no match, the table will show `No Data Found`.
