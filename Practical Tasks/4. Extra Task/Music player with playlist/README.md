# Music Player with Playlist

A simple music player website built with HTML, CSS, and JavaScript. It lets you view songs, add them to a personal playlist, and control playback.

## How the project works

- The page shows a list of songs from the JavaScript file.
- You can click the Add button to move a song into your own playlist.
- Click a song in your playlist to select it.
- Use the Play, Pause, Stop, and Shuffle buttons to control the music.
- The audio player plays the selected song from the Music folder.

## Project files

- index.html: the main page structure
- style.css: the design and layout
- script.js: the song list and player logic
- Music/: contains the audio files

## How to run

1. Open the project folder.
2. Open index.html in your browser.
3. Start playing songs from the playlist.
