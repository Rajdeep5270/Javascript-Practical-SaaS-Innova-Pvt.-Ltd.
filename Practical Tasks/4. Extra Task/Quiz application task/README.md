# Quiz Application

A simple JavaScript quiz app built with `index.html`, `script.js`, and `style.css`.

## How to run

- Open `index.html` in your browser (double-click the file or serve with a static server).

## How it works

- Questions are defined in `script.js` as an array.
- The app shows one question at a time with multiple-choice answers.
- Select an answer and submit; the app gives immediate feedback and advances to the next question.
- The app tracks your score and shows the total at the end with an option to restart.

## Files

- `index.html`: HTML markup and containers for the quiz UI.
- `style.css`: Styles for layout and appearance.
- `script.js`: Quiz data and logic (questions array, scoring, UI updates).

## Customize

- Add, remove, or edit questions by modifying the `questions` array inside `script.js`.
- Tweak styles in `style.css` or change the layout in `index.html`.
