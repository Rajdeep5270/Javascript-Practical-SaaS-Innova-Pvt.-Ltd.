# Quote of the Day Application

A simple web app that displays a random quote and author from an API. The app shows a loading message while fetching quotes and updates the content each time the user clicks "Next Quote".

## Files

- `index.html` - page structure and button trigger
- `style.css` - app styling
- `script.js` - fetches quotes from the API and updates the page

## How to use

1. Open `index.html` in your browser.
2. The app will fetch a random quote automatically.
3. Click the **Next Quote** button to load another random quote.

## Notes

- Quotes are loaded from `https://dummyjson.com/quotes`.
- The app displays a loading message while waiting for the API response.
