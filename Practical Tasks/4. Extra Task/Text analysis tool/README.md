# Text Analysis Tool

This project is a simple web-based text analysis tool.

How it works:
- Open `index.html` in a browser.
- Enter or paste text into the input area.
- The tool analyzes the text and shows results based on the script logic.
- The results appear immediately in the browser.

Files:
- `index.html`: the web page structure.
- `style.css`: page styling.
- `script.js`: text analysis functionality.
