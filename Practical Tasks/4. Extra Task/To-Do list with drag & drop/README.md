# To-Do List with Drag and Drop

A simple to-do list app where you can add tasks and reorder them by dragging and dropping.

## Features
- Add new tasks
- View all tasks in a list
- Reorder tasks using drag and drop
- Simple and easy-to-use interface

## How to Run
1. Open the project folder.
2. Open the file named `index.html` in your browser.
3. Start adding and arranging your tasks.

## Files
- `index.html` - Main page structure
- `style.css` - Basic styling for the app
- `script.js` - Task adding and drag-and-drop logic

## Notes
This project is built with plain HTML, CSS, and JavaScript.
