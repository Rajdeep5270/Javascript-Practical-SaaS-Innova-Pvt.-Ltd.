# Multiple API Request

A small JavaScript practice project demonstrating a simple front-end app that makes multiple API requests.

## Files

- `index.html` - Page structure and app container.
- `style.css` - Basic styling for the interface.
- `script.js` - JavaScript logic for fetching and displaying data from APIs.

## How to use

1. Open `index.html` in a browser.
2. The app will run the JavaScript code and fetch data from the APIs.
3. Results will display on the page.

## Notes

- This is a practice task focused on working with multiple API calls in client-side JavaScript.
- No build step is required.
