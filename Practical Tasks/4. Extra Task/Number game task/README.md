# Number Game

A simple number guessing game built with HTML, CSS, and JavaScript.

## How to use

1. Open the project folder in your browser.
2. Open the file named `index.html`.
3. The game will load and show a number guessing challenge.
4. Enter your guess in the input field.
5. Click the button to check your answer.
6. Follow the on-screen hints until you guess correctly.

## Requirements

- A modern web browser such as Chrome, Edge, or Firefox.

## Notes

- No installation is required.
- Just open the HTML file to start playing.
