# Task 2 - JavaScript Practice Project

Simple task management practice project built with HTML, CSS, and JavaScript.

## Description

This project demonstrates a small frontend-only task manager. It includes a task creation page, a task view page, and an edit page. The project uses JavaScript to handle form interactions and update the visible task list without backend storage.

## Files

- `index.html` - Main page for adding and viewing tasks.
- `style.css` - Styles for the project.
- `add-script.js` - JavaScript for adding new tasks.
- `view-script.js` - JavaScript for viewing tasks.
- `edit-task.html` - Page for editing a task.
- `edit-script.js` - JavaScript for editing tasks.

## How to Use

1. Open `index.html` in your browser.
2. On the main page, fill in the task details and submit the form to add a task.
3. After adding a task, it will appear in the task list on the same page.
4. To change a task, click the edit link or button and open `edit-task.html`.
5. Update the task fields and save the changes.

## Notes

- This is a small frontend-only practice project.
- Task data is not saved to a backend or database.
- Refreshing the page will clear tasks unless browser storage is implemented.
