# Recipe Management System

A simple client-side Recipe Management System built with HTML, CSS, and JavaScript.

## Features

- Add a recipe with name, ingredients, and description
- View all saved recipes
- Search recipes by ingredients
- Edit an existing recipe
- Delete a recipe
- Stores recipe data in browser `localStorage`

## Files

- `index.html` - Add recipe page
- `view.html` - View and search recipes
- `editReceipe.html` - Edit existing recipe page
- `style.css` - Shared styles for the app

## Usage

1. Open `index.html` in a browser.
2. Add a recipe and submit the form.
3. Use the navigation link to go to `view.html`.
4. From the view page, edit or delete recipes.

## Notes

- Data is stored locally in the browser, so recipes will remain until local storage is cleared.
