# Text Analysis Tool

## How to Use

1. Open `index.html` in a web browser.
2. Type or paste text into the input field.
3. Click the **Click to Analyze Text** button.
4. View the results:
   - **Total Length** shows the number of characters excluding spaces.
   - **Word Count** shows the number of words.
   - **Frequency of Words** shows how often each word appears.

That is all you need to do to use this project.
