# Simple Task Manager Application

This project is a small task manager built with HTML, CSS, and JavaScript.

## How to Use

1. Open the project folder in your browser.
2. Open the file named `addTask.html`.
3. Enter a task name in the input field.
4. Click the add button to save the task.
5. The task will appear in the list below.
6. You can remove tasks by clicking the delete button next to them.

## Notes

- This is a simple local app, so your tasks will be stored only while the page is open unless you add extra persistence later.
